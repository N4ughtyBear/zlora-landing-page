# Zlora - Landing Page Modern & Cepat

Landing page performa tinggi yang dirancang khusus untuk UMKM, brand produk, dan agensi yang mengutamakan kecepatan muat (*lightweight*), estetika visual modern, dan konversi penjualan instan via WhatsApp.

---

## 🚀 Fitur Utama

- **Ultra Fast Performance**: Struktur kode HTML/CSS murni tanpa framework berat, menghasilkan kecepatan akses instan (< 1 detik).
- **Mobile First & Fully Responsive**: Tampilan adaptif presisi di berbagai ukuran layar smartphone, tablet, dan desktop.
- **Direct-to-WhatsApp Funnel**: Seluruh tombol CTA terintegrasi dengan tautan WhatsApp bisnis lengkap dengan pesan prefilled otomatis.
- **Modern Interactive Elements**:
  - FAQ akordeon interaktif (native `<details>` & JavaScript).
  - Floating WhatsApp contact button dengan animasi pulse online.
  - Interactive product size picker pada halaman demo produk.
- **SEO & Social Ready**: Meta tags Open Graph, Twitter Cards, dan Schema.org JSON-LD (`ProfessionalService`) terpasang.
- **Optimized Media**: Seluruh aset gambar dikompresi hingga 90% lebih ringan tanpa mengorbankan ketajaman tampilan.

## 💻 Cara Menjalankan Secara Lokal

Cukup buka file `index.html` langsung di browser Anda, atau gunakan live server:

### Menggunakan VS Code Live Server
1. Buka folder proyek di VS Code.
2. Klik kanan pada `index.html` lalu pilih **Open with Live Server**.

### Menggunakan Node.js `npx serve`
```bash
npx serve .
```
Akses di browser pada `http://localhost:3000`.

## 🌐 Deploy ke Hosting

Proyek ini merupakan static site murni, sehingga dapat langsung di-deploy secara gratis dan instan ke:
- **Vercel**: Import repository GitHub, biarkan build setting default (Other), klik **Deploy**.
- **GitHub Pages**: Buka **Settings** > **Pages** > pilih branch `main` root `/` > **Save**.
- **Cloudflare Pages / Netlify**.
